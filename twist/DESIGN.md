# twist：定常速度场配准

## 端到端数据流与张量形状

以下以默认灰度图、`image_size=64`、`patch_size=8`、`token_dim=256` 为准，b 为 batch 大小，N=64 为每张图的 token 数。这里的逐像素分辨率指模型输入的 64×64；GNT 原始图在数据预处理时已裁剪、等比例缩放、居中到固定画布。

```text
预处理 uint8 字图 + 同字跨书写者索引
  → 抽样 [b,2] 原图 ID；A/B 合并去重
  → 缩放、逐图 min/max 归一化；准备 D_A、D_B
  → A、B [b,1,64,64]
  → 共享 patch 投影：每个 8×8 patch 的 64 个灰度值 → 256 维
  → A/B 各 [b,64,256]，加二维 patch 位置编码
  → 8 个双流块，保留每个 token 和全部残差
  → B token 的 LayerNorm + Linear(256,128)
  → 每个 patch 64 组 (vx,vy)，直接重排为 v [b,2,64,64]
  → 原图外圈速度置零
  → 同一 v 积分 exp(v)、exp(-v)，两个网格均 [b,64,64,2]
  → 从原始 A/B 各采样一次，得到未混合的双向配准图
  → 双向相似度 + 双向距离场 + 未缩放 v 的平滑
  → 反向传播 → 优化器梯度范数裁剪 → Adam 更新
```

| 环节 | 张量形状 | 信息或梯度处理 |
|---|---|---|
| 驻留字图 | `[总图数,S,S]` uint8 | S 为预处理尺寸；保留灰度，排除恒定图 |
| 批内唯一字图 | `[U,1,64,64]` FP32，U≤2b | A/B 同图共用缩放、归一化和距离缓存 |
| 原始 A/B、D_A/D_B | 各 `[b,1,64,64]` FP32 | 距离场用原图准备，停止其自身梯度 |
| patch 投影 | 各 `[b,256,8,8]` → `[b,64,256]` | 8×8 是 token 排列；每个 token 保留 patch 内像素位置特征 |
| 每个 SA/CA | 输入、输出 `[b,64,256]` | 8 个头，每头 32 维；可读取全图所有 patch |
| 每个 FFN | `[b,64,256]` → `[b,64,1024]` → `[b,64,256]` | A/B 两支均有 FFN；残差保留原 token |
| 像素速度头 | `[b,64,128]` | 128=8×8×2，包含每个像素的独立 x/y 输出分量 |
| 像素重排与边界处理 | `[b,8,8,8,8,2]` → `[b,2,64,64]` | 外圈 252 个像素固定，62×62 个内部像素参与预测 |
| 正反向位移 | 各 `[b,2,64,64]` FP32 | 从 ±v/128 开始，各平方 7 次；保留计算图 |
| 正反向采样网格 | 各 `[b,64,64,2]` FP32 | 通道顺序 `(x,y)`，内部坐标范围约定 [0,1] |
| 配准图、采样距离 | 各 `[b,1,64,64]` FP32 | 分别采样 A、B、D_A、D_B；坐标梯度回到 v |
| 三项 loss 与 total | 标量 | 两个方向共同训练同一个速度头和全部双流块 |

没有 token 池化、全图单向量压缩、8×8 速度网格或从粗速度场上采样的步骤。默认输入投影为 64→256，输出为 256→128，维度上足以保留局部输入并输出本 patch 全部速度分量。初始化实例中两投影的矩阵秩分别为 64 和 128；这说明不存在结构上的强制低秩压缩，不代表训练后一定使用全部信息。修改 patch 大小或通道数时，应重新比较 `in_channels*patch_size²`、`token_dim` 与 `2*patch_size²`。

## 数据准备与传输

`train-all-pair/pairs.py` 一次加载所有 writer 的 uint8 字图，训练过程中不再打开 NPY 文件。配对只发生在相同 train/val 划分、同一字符、不同书写者之间。每轮每张可配对图作为 A 一次，B 随机从同字的其他书写者中选取；不展开全部两两配对表。`standards.npy` 不参与当前手写图到手写图训练。

输入先缩放到模型尺寸，再逐图计算 `2*(pixel-min)/(max-min)-1`。尺寸相同时跳过缩放；不同尺寸使用带抗锯齿的双线性缩放。恒定图在建立配对索引前排除，缩放后成为恒定图的样本也排除。训练归一化和距离场阈值使用同一幅缩放后的图，避免目标与距离场错位。

默认 `preload_to_gpu=False`：将批内 A/B ID 合并去重，**在 CPU 完成缩放、归一化和缺失距离场准备**，然后按原配对顺序送入训练设备。消除了先将图像送入 GPU、再下载到 CPU 做 EDT 的回传。`preload_to_gpu=True` 则像素和归一化驻留 GPU，但 SciPy EDT 仍在 CPU，缓存未命中时仍需下载相关图像；此选项是否更快需实际测量。

D_A、D_B 共用按原图 ID 组织的 CPU LRU。缓存项为独立 FP32 张量，默认 8192×64²×4 bytes=128 MiB；一批里同一图只查找/计算一次，即使缓存小于本批唯一图数，也保留本批所需场直到返回。预览设置 `with_distance=False`，不查找或计算距离场。

这个缓存是按需计算和淘汰后的重算，**不是全数据集永久预计算**。若可配对图数远大于 8192，跨批随机访问可能导致低命中率。日志 `distance_cache` 记录累计 `hits`、`misses`、`hit_fraction`、`cached_images`、`capacity` 和 `prepare_seconds`；计数按批内唯一图计算，包含训练、日志重评和验证，不包含纯预览。`prepare_seconds` 统计缺失场的 CPU EDT，GPU 驻留模式下也包含其下载。可以比较相邻日志的增量来判断重算开销；缓存统计不随检查点恢复。

## 单个配准网络

输入 A、B 为同尺寸灰度图，白色 +1、黑色 −1；坐标归一化到 [0,1]²。A、B 各切 patch、编码一次，使用共享 patch 投影和固定二维位置编码。单个网络内堆叠 `num_blocks` 个双流模块，所有模块处理同一对 token 流：

- A：SA → FFN。
- B：SA → CA → FFN；CA 的 Q 来自 B，K/V 来自更新后的 A。
- 注意力与 FFN 均使用归一化及残差连接，最后一个 A 的 FFN 也参与 CA 输出。

全部模块完成后，每个 B token 经 `Linear(token_dim, 2*patch_size²)` 直接输出本 patch 每个像素的二维速度。默认为 `Linear(256,128)`，即每个 token 输出 8×8=64 组 `(vx,vy)`。按 patch 行列、patch 内像素行列和 x/y 分量重排成 `[batch,2,image_size,image_size]`，默认 `[batch,2,64,64]`。只将原图最外圈像素的速度置零，内部像素速度保持直接预测值。双线性插值用于积分中的场求值和映射复合。这里 v 定义为**反向采样映射**的生成速度，单位为归一化坐标/单位时间。

默认 64×64 输入、8×8 patch、token_dim=256、8 个头、8 个双流块、mlp_ratio=4。单网络共 14,799,744 个参数；没有串联配准阶段或阶段间图像重编码。

patch 投影的卷积核有独立的 patch 内像素权重，因此局部像素位置不会被平均掉。位置编码描述 patch 在全图的位置。速度头输出的第 `2*(py*8+px)+c` 个分量对应局部像素 `(py,px)` 的第 c 个分量，全图位置为 `(patch_y*8+py,patch_x*8+px)`，c=0 为 x、c=1 为 y。重排仅改变存储顺序，不进行插值或平均。

CA 的 A 侧只作为 memory，B 侧负责查询和最终解码；A 的最后一个 FFN 在最后一次 CA 之前运行，仍参与输出。相反方向的监督来自同一场的 exp(-v)，不需要第二个网络输出。交换输入重新运行网络时，架构本身没有强制 `v(B,A)=-v(A,B)`；双向损失也不等同于这项代数约束。

输出头默认 `head_init_std=1e-4`，偏置为零，从接近恒等映射的流开始。原 `1e-3` 对 256 维 token 的逐像素头会产生约 1 像素 RMS 的初始速度分量，较容易出现离散高频折叠；减小初始化只改变新训练起点，不限制训练后的速度幅值。

## 坐标、采样方向与梯度路径

所有几何量采用归一化坐标。64×64 时，x、y 的一个像素间距均为 1/63，速度的 0.1 对应约 6.3 像素/单位时间。几何入口将 BF16/FP16 速度转换为 FP32；显式 FP64 几何输入保留 FP64。图像与距离场采样、loss 在训练中使用 FP32，网络内部可以用 BF16。

`grid_sample` 使用反向采样：输出位置 q 查询原图位置 G(q)。若 A 的笔画在列 20、B 在列 28，那么正向网格在目标笔画处应查询约列 20，即该处的 x 位移约为 -8/63。速度符号应按这个采样方向理解，而不是把像素的前向运动方向直接当作采样位移。

只在调用 `grid_sample` 时把 [0,1] 转成 [-1,1]，统一 `align_corners=True`。图像/距离场使用 border padding；复合位移使用 zero padding。图像预处理缩放的 `align_corners=False` 是重采样画布的规则，两张图和各自距离场经历同一预处理，随后都使用同一几何坐标约定。

相似度的梯度沿“图像插值 → 采样网格 → 7 次位移复合 → 逐像素 v → 速度头 → B token → SA/CA/FFN → A/B 编码”传播。距离项沿相同网格路径传播，D 和软前景权重停止梯度；参考 Sobel 权重也停止梯度。平滑项直接从未缩放 v 回传，不经过积分。没有对 v、位移、CA memory 或中间 token 做 detach；边界置零只阻断最外圈速度输出的梯度。

## Scaling and Squaring

定常流满足

$$
\frac{d\phi_s(x)}{ds}=v(\phi_s(x)),\quad
\phi_0(x)=x,\quad
\phi_s=\exp(sv).
$$

`squaring_steps=n` 控制缩放指数。将速度乘以 s/2ⁿ，作为小步映射，再自复合 n 次；相当于 2ⁿ 个小步。默认 n=7，即缩放为 1/128 后做 7 次平方。n=0 使用一次 Euler 小步。

$$
d_0(x)=\frac{s}{2^n}v(x),\qquad
d_{k+1}(x)=d_k(x)+d_k(x+d_k(x)),\qquad
\phi_s(x)\approx x+d_n(x).
$$

速度与图像具有相同的空间分辨率，积分直接从逐像素速度开始，每次用双线性插值复合位移。积分入口校验分辨率一致。s 可以为负，反向流直接使用同一个场的 -v。**时间乘在速度上再积分**，不能将积分得到的最终位移直接乘 s。

连续流具有 φₛ ∘ φᵣ = φₛ₊ᵣ、φₛ⁻¹ = φ₋ₛ。有限网格的 Euler 初始化和插值带来数值误差；提高 n 可减少初始化误差，网格精度也会限制结果。边界零速度使连续流固定边界，实际离散映射的 Jacobian 仍需观察，不能宣称任意网络输出都严格无折叠。

## 双向中间画面

网络只运行一次，缓存 v；查询任意 t∈[0,1] 时重新积分缩放后的速度：

$$
A'_t(x)=A(\phi_t(x)),\qquad
B'_t(x)=B(\phi_{-(1-t)}(x)),\qquad
I_t(x)=(1-t)A'_t(x)+tB'_t(x).
$$

A 走 t，B 沿同一条流反向走 1-t，再按 (1-t)、t 混合。每个方向都从原始图像采样一次，避免逐帧图像插值累积模糊。t 支持标量或 [batch] 时间张量，首尾严格返回原始 A、B。

`RegistrationResult.image` 是未混合的 A(φ₁)，`reverse_image` 是未混合的 B(φ₋₁)。`render(t)` 返回混合图、两张变形图及两个采样网格。配准必须监督未混合端点；混合输出 I₁=B 本身，不能用它与 B 比较来训练网络。

标量 t=0/1 复用已缓存的端点网格和未混合配准图，并直接返回原始 A/B，不重新积分或采样。其他标量时间保持为 Python 标量，避免内部时间校验逐帧读取 GPU 标量；张量时间继续走可微积分路径，可对 t 求导。GIF 将全部灰度帧合并后传回 CPU 一次，再生成 PIL 图像。

## 有且只有三项损失

总损失由双向图像相似度、双向距离场和未缩放速度的一阶平滑组成：

$$
L=w_{\mathrm{sim}}L_{\mathrm{sim}}
+w_{\mathrm{dist}}L_{\mathrm{dist}}
+w_{\mathrm{smooth}}L_{\mathrm{smooth}}.
$$

`similarity_weight=1`、`distance_weight=1`、`smoothness_weight=0.001`。正反方向直接相加，不取平均。

### 双向图像相似度：微观对齐

$$
L_{\mathrm{sim}}
=\ell(A\circ\phi_1,B)+\ell(B\circ\phi_{-1},A).
$$

ℓ 使用 Sobel 梯度平方加权 MSE。对参考图 R，令 e=(P-R)²、g=|∇R|²，逐图计算 α·mean(e)+(1-α)·Σ(ge)/Σg。参考梯度停止传播，α=`mse_uniform_ratio`，默认 0.2；无边缘时退化为普通 MSE。反方向以 A 为参考计算边缘权重。监督未混合的配准端点，细调笔画的边缘和粗细。

### 双向距离场：宏观拉扯

分别预计算原始 A、B 的欧氏距离场 D_A、D_B。距离指向灰度 <= `distance_threshold` 的原始墨迹，使用归一化坐标单位；默认阈值为 0。

前景权重采用原图的软墨迹覆盖率：m(I)=clamp((1-gray(I))/2,0,1)。黑色为 1、白色为 0、灰色连续保留覆盖程度，并停止梯度。这样保留实际笔画区域与抗锯齿信息，避免细化骨架引入分叉和中心线变化。

$$
L_{\mathrm{dist}}=
\frac{\sum_q m_B(q)D_A(\phi_1(q))^2}{\sum_q m_B(q)+\varepsilon}
+
\frac{\sum_p m_A(p)D_B(\phi_{-1}(p))^2}{\sum_p m_A(p)+\varepsilon}.
$$

逐图分别归一化后对 batch 平均；两个方向使用同一实现。原始距离场和 m_A、m_B 均停止梯度，采样网格保留梯度。即使笔画尚未重叠，距离场也能在图像相似度缺少有效坐标梯度的位置提供更长程的对齐信号。平方距离的梯度随距离与位置变化，并非恒定或处处非零。

训练为 A、B 准备距离场并缓存，传输和淘汰规则见上面的“数据准备与传输”。

### 速度场平滑：控制空间变化

$$
L_{\mathrm{smooth}}=
\operatorname{mean}\|\partial_x v\|^2+
\operatorname{mean}\|\partial_y v\|^2.
$$

使用网络输出经边界置零后的**未缩放**速度场 v，差分除以原图归一化像素间距。它是温和的一阶黏性平滑，允许局部收缩、膨胀和笔画粗细变化。

有限的一阶平滑能量是软正则，不能直接推出 v∈C¹，也不是微分同胚的充要条件。若速度场具有足够的空间正则性（例如 C¹）、且解在所需时间范围内存在，其连续流具有微分同胚性质。当前双线性插值是连续、分片光滑的局部 Lipschitz 场，可保证连续 ODE 解的唯一性，但不应将其等同于全局 C¹；稠密网格积分与插值仍有数值误差。

日志中的最小 Jacobian 和非正行列式比例用于几何诊断。总损失只包含上述三项；优化器梯度范数裁剪仍用于训练数值稳定。

## 训练与检查点

当前训练入口为 [train-all-pair](train-all-pair/README.md)，A、B 来自不同书写者的同字手写图。预览 GIF 使用上述双向中间画面。模型和 loss 配置位于 [config.py](config.py)。

每次更新只运行网络一次，两个方向通过同一 v 完成积分和监督。默认 Adam、batch=32、lr=1e-4；默认累计更新 `steps=1_000_000`。`precision=auto` 在支持 BF16 的 CUDA 上使用 BF16 网络计算，几何和 loss 保持 FP32。保留非有限 loss 检查与优化器梯度范数裁剪的数值检查。

普通日志每 50 步在更新后的参数上重评当前批次，因此日志步会额外运行一次网络、双向积分和三项 loss；这是日志语义的代价，不发生在每一步。每 1000 步验证/保存，默认固定 512 对验证图、预览其中 4 对；启动和运行结束也执行。验证的各项 loss、速度最大值和 Jacobian 统计在设备上累计，整个评估结束后统一传回，避免每批逐指标同步 GPU。预览每对图只运行一次网络，之后复用 v 查询各帧。

逐像素速度场检查点使用 version=3。旧粗速度网格（version=2）与位移串联模型的输出头或参数结构不同，需从新的输出目录开始训练；预处理字图可以继续使用。version=3 内续训恢复模型配置、优化器动量、抽样顺序和随机状态，训练/loss 设置按当前文件或命令行读取。

本次数据准备、指标汇总、预览优化及初始化调整没有改变参数形状，version=3 检查点仍可续训。恢复已有权重不会重新初始化速度头，因此更小的默认初始化只影响新训练。检查点不包含全部像素、距离缓存或缓存命中统计。

## 开销核算与本次检查

默认 8 个双流块包含 24 次注意力和 16 个 FFN。忽略归一化、激活、softmax 与几何采样，网络每对图的矩阵乘加量约为：

$$
\mathrm{MACs}=K\big[(12+4r)ND^2+6N^2D\big]
+2NP^2C D+2NP^2D,
$$

其中 K=8、r=4、N=64、D=256、P=8、C=1，约 0.994 G MACs/对图；按一次乘加为两次浮点运算，batch=32 的网络前向约 63.6 GFLOPs。FFN 约占乘加的 54.0%，注意力 Q/K/V/输出投影约 40.5%，注意力相关矩阵乘法约 5.1%。默认 token 数只有 64，主要矩阵开销在宽度投影与 FFN，而不是 N² 注意力矩阵。参数中 FFN 约 8.409M，注意力投影约 6.316M。

逐像素积分的空间大小为 64×64。完整训练前向每批调用 `grid_sample` 18 次：正反方向各 7 次速度复合、各 1 次原图采样、各 1 次距离采样。中间 render 每帧 16 次，标量首尾为 0 次；n=7 不意味着执行 128 次采样。21 帧预览在网络前向之后只为 19 个中间时间积分。

FP32 模型参数约 56.5 MiB，加梯度及 Adam 的两份动量，基础存储约 226 MiB，另需激活。batch=32 时单支 token 约 2 MiB，单个 FFN 隐藏张量约 8 MiB，一批稠密速度场约 1 MiB；多个块保存的训练激活才是额外显存开销的主要来源。BF16 可减少部分网络激活，几何 FP32 不随其缩减。

2026-10-09 在本机 PyTorch 2.9.0、CPU 单线程、默认完整网络和合成平移笔画上做了暖机及三次前向/反向测量。下表仅用于判断本机各段相对开销，不代表 CUDA 性能；不包含 Adam 更新、数据读取、EDT 或 GIF 保存。

| 每次前向/反向的阶段 | batch=1 中位数 | batch=32 中位数 |
|---|---:|---:|
| 速度网络 | 约 31 ms | 约 857 ms |
| 双向积分和原图采样 | 约 2.0 ms | 约 57 ms |
| 三项 loss 前向 | 约 0.7 ms | 约 10 ms |
| 三项 loss 的完整反向传播 | 约 50 ms | 约 1679 ms |

同机另测 64 张 64×64 图的 CPU EDT，暖机后五次中位数约 6.0 ms。CUDA 网络更快时，这种同步 CPU 准备可能占更大比例，实际比例需结合真实数据、缓存命中率和显卡测量。本地没有 CUDA 或真实 prepared 数据，本次未测显卡吞吐量及全数据集实际缓存命中率。

检查确认默认 `[b,64,256]→[b,64,128]→[b,2,64,64]`，batch=1/32 的 loss 和全部参数梯度均有限且非零，三项 loss 各自都能回传到 v。像素排列、x/y 分量、单像素梯度定位、双向距离场长程梯度、中间时间、混合精度、缓存淘汰、指标汇总和断点续训由测试覆盖。

本次修复了四类开销：批内重复图像的重复准备、CPU 驻留模式下缺失距离场的 GPU 往返、验证逐指标 GPU 同步、GIF 首尾重积分及逐帧回传。保留更新后重评训练日志，以维持其含义。

初始化还存在实际数值风险：原 std=1e-3 在合成样例的种子 0/8 中分别出现 2/5 个非正单元（正反共 7938 个单元），n 从 7 增至 11 仍存在；种子 42 未出现。改用 std=1e-4 后这三个实例的速度分量 RMS 约 0.094–0.104 像素，最小 Jacobian 约 0.56–0.65，未出现非正单元。这个结果支持从近恒等流起步，不能推广成对任意训练后输出无折叠的保证。

## 仍需观察的限制

| 项目 | 当前影响与观察方式 |
|---|---|
| 原始图的预处理分辨率 | 若预处理文件已是 64×64，改成 128 输入只是放大既有像素，无法恢复丢失的细笔画；需要更高精度时从原始数据准备更大画布 |
| patch 接缝与高频速度 | 每个像素有独立输出，但相邻 patch 的解码没有硬连续约束；平滑差分覆盖所有邻接像素，包括接缝。需看配准图和 Jacobian，不能只看动画混合效果 |
| 空间插值与离散折叠 | Euler 初始化、双线性场插值、有限网格的映射表示均有误差；增加 n 主要减小时间初始化误差，无法消除空间离散误差 |
| 超出画布的采样 | 过大的离散流可能越界；图像/距离场 border padding 在越界方向没有有效坐标梯度，零位移外延也会影响复合。边界置零及较小初始化有帮助，训练后仍需观察 Jacobian 与速度 |
| 随机配对的 EDT 重算 | LRU 容量远小于图数时可能频繁重算。先看命中率和准备耗时，再决定扩大缓存或另做完整离线距离场缓存；当前没有异步数据预取 |
| 增大分辨率或减小 patch | token 数 N=(H/P)² 增长；投影/FFN 随 N，注意力相关矩阵随 N² 增长，不能照搬默认 64 token 的开销结论 |
| 双向监督与交换对称性 | 同一场的正反积分受共同监督，但网络交换 A/B 的输出没有强制反对称；当前仍严格保持三项 loss |
| 手写字的真实拓扑差异 | 连续可逆形变无法完整改变断笔、连笔、孔洞等拓扑；混合帧可以平滑视觉过渡，但不证明端点配准成功 |
