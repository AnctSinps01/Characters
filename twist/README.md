# twist

用连续空间变形约束线条图之间的过渡。输入两张近似同构的线条图 A、B，得到一条合理轨迹，并能查询任意 `t ∈ [0,1]` 的画面。

主结构通过平滑、可逆的变形场运动；小幅外观分支负责亮度和明确的微小噪声。输入不限于汉字，也可为字母、图标、曲线和其他线条图。

当前仅保存规划，未编写模型、训练或采样代码。具体任务边界、数学定义、模型候选、约束、数据和验收步骤见 [`DESIGN.md`](DESIGN.md)。

公共字体、参考项目、论文与现有依赖位于仓库根目录。原 DiT + flow matching 实现位于 [`../DiT-flow/`](../DiT-flow/README.md)。
